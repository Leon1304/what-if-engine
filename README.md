# what-if-engine

Engine for the /what-if video skill (Claude): Three.js template, headless renderer, assembler, offline voice-over.

- `template.html` – engine + example story/scene (zombie farm)
- `render.mjs` – frame-exact renderer (shots, video, cover, audio, remux). Default 2K (1440×2560): `out.mp4` = YouTube master (CRF 18); `--ig` adds an Instagram copy (1080×1920), not used by default
- `assemble.py` – builds `<slug>.html` from `<slug>.story.js` + `<slug>.scene.js`
- `voice.py` – Kokoro TTS voice-over with word timings
- `docs/API.md` – full scene API reference (the skill's SKILL.md keeps only the rules and a short overview)
- `tests/` – smoke test: `bash tests/run.sh` builds the example story and every test scene and renders a few frames; runs on GitHub (workflow `test`) for every engine change

## Rendering on GitHub Actions
Push an assembled page to `renders/<slug>.html` (output of `assemble.py`, voice embedded). The `render` workflow splits it into 12 frame blocks rendered in parallel, then encodes `<slug>.mp4` (YouTube master, 2K) and `<slug>-cover.jpg` and attaches them to the release `render-<slug>`:
`https://github.com/Leon1304/what-if-engine/releases/download/render-<slug>/<slug>.mp4`
Manual run: Actions → render → Run workflow (page path, width 1440 / 2160 / 1080).

## Engine v2.7 (Nov 2026): conspiracy board, meters, split screen, globe, size comparison, loop
- **Conspiracy board:** `conspiracyBoard(p, x, z, { items: [{ kind: 'photo' | 'note' | 'clip', icon, text }], links: [[i, j, snapT], …], cross: [[i, t], …], fall, wall })` — cork board on an easel with drawn photos (ufo, moon, pyramid, eye, globe, bird, ship, monster, camera, rocket, skull, question), sticky notes and clippings; red strings snap and swing down one by one, red ✗ stamps, the board topples. `B.item(i)` anchors callouts.
- **Meter stat:** `{ type: 'meter', left: 'Nope', right: 'Totally real' }` — needle gauge 0–100 (red / yellow / green), the needle swings and trembles while it moves (Believability, risk, danger).
- **Timeline stat:** `{ type: 'timeline', from, to, marks: [[1969, 'Apollo 11'], …] }` — year strip with playhead; close marks put their label below; `fmt: 'year'` (negative = BC).
- **Split screen:** `SPLIT = [{ t, dur, a: 'main' | { p, l, fov, p2, l2 }, b: { … }, labels: ['Myth', 'Reality'], kinds: ['bad', 'good'] }]` — two cameras at once (top / bottom), wipes in from below with labelled halves; each half has its own aspect, sky and shadow box (no AO, lens blur or callouts meanwhile).
- **Globe tools:** `globeMark(planet, lat, lon)` (pin + pulsing ring), `globeArc(planet, [lat, lon], [lat, lon], { t0, t1, h })` (great-circle arc that draws itself, with a head dot), `globeArea(planet, [[lat, lon], …])` (filled region + outline) on `planet()` and `layers()`; they spin with the surface and return callout anchors.
- **Size comparison:** `lineup(p, x, z, [{ kind, h, label }], { labels })` — human, dog, cow, car, bus, truck, house, tree, palm, tower, lighthouse, silo, rocket, pyramid, plane, ship, whale, block, each scaled to its real height and placed side by side; height tags in metric · imperial; `L.shot(t, dur)` gives CAM keys that pan from the smallest to the biggest.
- **X-ray skeleton:** capsule bones with knobbly ends, curved ribs, vertebrae, pelvis, sternum, collarbones, skull with eye sockets.
- **Cutaway globe:** finer, smooth surface with soft coastlines and a cloud layer (`clouds: false` to drop it).
- **Loop ending:** `CFG.loop: true` — the last 0.3 s whip away and the cards fade, so the restart lands on the hook like the next shot.
- Callout `text` / `sub` may be functions; hidden why chips and delta pop-ups take no room in their stat row.

## Engine v2.6 (Nov 2026): explainer shorts
`CFG.kind: 'explain'` turns a video into an explainer: badge **Explaining** — `'conspiracy'` does the same for conspiracy and myth checks with the badge **Conspiracy** (no episode number; colour = `CFG.accent`, `'auto'` picks one from the title), calm `documentary` voice by default. Every tool also works in story videos. Full notes: end of the STORY block in `template.html`.
- **Callouts on 3D points:** `CALLOUTS = [{ t, dur, at, kind: 'label' | 'arrow' | 'ring' | 'tag', text, sub, side, off, value, fmt }]` or `callout(at, t, o)` from the scene. `at` = track name, `[x,y,z]`, `t => [x,y,z]` or a rig. Leader lines and arrows draw on, rings draw round, labels stay in the safe area, flip sides when cramped and never stack (layout is a pure function of t). Live values: `text: 'Falling at {v}', value: t => v, fmt: 'speed'`.
- **Freeze frame:** `FREEZE = [{ t, dur, label, sub }]` stops the scene dead (camera, voice and captions go on), drains the colour, white frame + label chip, impact/whoosh. After it the scene runs `dur` s behind: scene times = `ST(videoTime)`.
- **X-ray:** `xray(rig, { t0, t1, path: 'bolt' | 'venom' | 'blood' | [joints], grow: [a, b] })` — glassy see-through body, skeleton, glowing path (lightning, venom, blood) with pulses.
- **Cutaway sphere:** `layers(p, x, y, z, { r, kind: 'earth' | 'moon' | 'sun' | 'plain', layers, cut: 90 | 180, face, open: [t0, t1], tunnel, labels })` — wedge cut out, unlit layer faces with gradient, hot cores glow, lid lifts out; `E.at(i)` anchors callouts.
- **Cross-section block:** `strata(p, x, z, { w, d, layers: [{ h, color, name, opacity }], top, labels })` — soil, quicksand (see-through layers), snow pack, ocean depth; `Q.at(i)`.
- **Gauge:** `RULER = { label, show, hide, min, max, fmt, value | keys, marks: [[v, 'Everest'], …], invert, log }` — vertical scale on the left, pointer with the value, marks light up and pop when passed.
- **Cards:** `FACTS` (big number that counts up + source line), `MYTH` (claim + FALSE / TRUE / HALF TRUE / MYTH stamp that slams on), `GUESS` (guess-first card with countdown, answer card later). Captions move to the lower third and callouts/gauge step aside while a card is up.
- **Steps:** `STEPS = [[t, 'The heat'], …]` → numbered chip next to the badge (1/3 The heat), tick on each step.
- **Units and graph:** stat `fmt: 'speed' | 'dist' | 'height' | 'depth' | 'temp' | 'mass' | 'g'` (metric in) → "195 km/h · 121 mph" (`CFG.units: 'both' | 'metric' | 'imperial'`); stat `type: 'graph'` draws the value's curve (`mark` = dashed reference line). Long stat rows wrap instead of running into the app buttons.

## Engine v2 (Nov 2026): motion, faces, nature, image
- **Jointed figures:** hips, knees, feet, elbows; feet are placed by IK and stay planted, hips bob and sway, shoulders counter-rotate, arms swing opposite to the legs. Everybody breathes, blinks and glances around. `walk()` accelerates/brakes, turns ahead of corners and blends walk ↔ idle.
- **Acting:** `react(f, t, 'startle'|'hit'|'shrug'|'nod'|'shake'|'facepalm'|'wave'|'sigh'|'flinch')`, `jump(obj, t, { h })` (crouch, stretch, squash; any object), `figure({ look: 'cam' | [x,y,z] | name })`.
- **Faces:** eyes with pupils and glints, nose, ears, cheeks, lips, teeth, mouth corners. Expressions: calm happy scared angry shout sad surprised smug annoyed. `talk: [[t0, t1]]` or `t => bool` moves the lips (Dr. Steve talks during his beats automatically). Animals have eyes and nostrils; chickens head-lock when they walk.
- **Crowds:** same jointed body, per-member quirks (arm height, head tilt, dangling arm, stumbles).
- **Nature:** detailed trees (round, pine, snowpine, birch, dead, palm), rock clusters, cacti, `bush()`, `stump()`, `log()`, ground colour patches, wind sway (`CFG.wind`). `biome('farm'|'forest'|'beach'|'desert'|'snow'|'swamp'|'city'|'moon')` dresses the scene and keeps buildings, paths, crowd lanes and camera sight lines free.
- **Image:** ambient occlusion (`CFG.ao`), bloom (`CFG.bloom`), shadows fitted to the shot (`CFG.shadowFit`), real motion blur on fast frames (`CFG.motionBlur: 'auto'|'all'|false`, `MBLUR = [[t0, t1]]`), rounded smooth-shaded figures (`CFG.smooth`), optional environment light (`CFG.env`).
- **Captions:** long narrated beats are shown in pages (one sentence or ≤ `CFG.capWords` = 7 words) that follow the voice.
- **Motion capture:** `model('robot')` + `anim(rig, [[t, 'Wave'], …])`, works with `walk()`/`pose()`; see `models/README.md`.
- Render time: about 1.8× per frame, up to 3× on motion-blurred frames. Faster: `motionBlur: false`, `ao: 0`, `bloom: 0`.
- **Buildings & streets (v2.1):** farmhouse (plinth, framed windows with shutters and flower boxes, panel door, shingles, porch railing), barn (plank seams, corner trims, cupola + weathervane), silo, windmill (12-blade wheel, tail vane), fences with caps. City towers in three facade styles with real relief — `glass` (ledges, mullions), `brick` (recessed windows with sills and lintels, fire escapes, cornice), `deco` (pilasters, spandrels, belt courses, stepped crown, spire) — plus street level shop windows, awnings and entrances. `city()` adds paving, curbs, zebra crossings, manholes, street lights that glow at night, trees, planters, benches, bins, hydrants, bus stops, traffic lights (`props: false` = bare).
- **Vehicles & aircraft:** `vehicle(p,x,z,{kind})` car · sports · taxi · police (flashing light bar) · van · pickup · bus · truck · tractor (lights, bumpers, grille, mirrors, hubcaps); `traffic()` mixes the types (`kinds: […]`). `plane(p,{kind:'jet'|'prop'|'airliner'})`, `heli(p)`, `fly(obj, [[x,y,z],…], {t0, speed, loop, bank})`; `boat(…,{kind:'boat'|'yacht'|'ship'})`. Street furniture: `streetlight`, `planter`, `busstop`, `bench`, `hydrant`, `trashcan`, `trafficLight`.
- **Looks:** `figure({ hatStyle: 'straw'|'cap'|'beanie'|'cowboy', capBack, hairStyle: 'short'|'buzz'|'spiky'|'long'|'bun'|'curly'|'mohawk', glasses })`; `char('you', { outfit: 'cap' | ['capBack', 'shades'] … })` presets (OUTFITS). Default "you" has hair, no hat; series keep their look in cast.json.
- **Thumbnails:** `render.mjs --cover` renders a thumbnail in the video's look: `THUMB = { t, text: 'Zombies *ate* my _farm_', sub: 'Part 3', cam: { p, l, fov }, expr, lookCam, ring, arrow }` (all optional; `--plain` = bare frame).
- **Bloom** only takes the excess above `bloomThreshold` (1.2), capped: lamps, fire, sirens and zombie eyes glow, floodlit surfaces don't wash out.
- **Interactions (v2.2):** `carry(rig, obj, { pick, drop, throw: { t, to, h }, both })` (bend down, carry with one or both hands, put down or throw with wind-up), `toss(obj, t, { to, h, bounces, spin, float })` (arc + bounces; lands in water with a splash), `push(rig, obj, { t0, t1, to })`, `knockAway(obj, t, { dir, power })`, `shatter(obj, t)`, `wobble(obj, t)`. Doors: `openDoor(house | barn | car | gate, t, { i, close })`, `openWindow(house, t)`, `gate(p, x, z)`. `sit(rig, t, { seat: bench | [x,y,z], t1 })`, `enter(rig, vehicle, t, { out })`. Light: `flashlight(rig, { t0, t1 })`, `headlights(vehicle, { t0 })`, `phone(rig, { t0, t1, light })`, `lightning(t, { x, z })`, `lightningStorm(t0, t1)`. Traces: `walk(…, { prints: true | hex })` footprints, `drive(vehicle, pts, { t0, speed, tracks, dust })` (wheels turn, nose dips when braking, tyre tracks + skid marks, brake dust), `splash(x, z, t)`.
- **Stats with a purpose (v2.3):** every stat gets an icon (from its label) and a type: `num` (default), `bar` (0–100 meter, colour by level), `timer` (`until: t | 'end'`, `scale`, shown as a countdown clock), `stars` (wanted level 0–5), `vs` (`a: 1` → "1 vs 376"). `why: [[t, 'reason']]` shows a chip next to a jump, `crit` / `critAbove` turn the row red and pulsing, `big: true` makes it the hero stat, `fmt: 'money' | 'clock' | 'pct'`. Changes jolt and show the delta.
- **Space (v2.3):** `planet(p, x, y, z, { kind: 'earth'|'moon'|'mars'|'gas'|'ice'|'lava', r, ring, clouds, atmosphere, axis, spin })` (continents, ice caps and clouds; craters; bands; glowing lava cracks; atmosphere glow; banded rings; planets ignore fog), `spaceSky({ nebula, nebula2, glow, milkyway })` (nebula clouds, Milky Way band, bright stars; with SKY `'space'`), `astronaut({ expr, patch, visor })` (helmet with tinted visor and visible face, backpack, chest panel, gloves) + `walk(…, { mode: 'lowg' })` (Moon lope) + `floatIn(rig, { t0, drift, spin })` (zero-g), `spaceship(p, { kind: 'shuttle'|'capsule'|'fighter'|'ufo'|'cruiser', trail, beam })` (glowing engines, trails that follow `fly()`), `satellite(p, { kind: 'classic'|'starlink' })`, `station(p)`, `lander(p, x, z)`, `flag(p, x, z)`, `crater(p, x, z, r)`, `asteroids({ n, at, r })`, `biome('moon')` with craters. Build different locations (orbit, Moon surface) ≥ 1.5 km apart (e.g. orbit set at x = 4000), never stacked: the camera sees 1.2 km.
- **Spaceships (v2.4):** panelled hulls, lit window rows, blinking nav lights, engine bells with glowing rims and flickering exhaust plumes (`thrust: 0..1 | t => …`), cockpit glass with pilot (fighter), docking ring/RCS/radiators (capsule), black heat-tile belly and double-delta wings (shuttle), turrets/greebles/hangar glow (cruiser), chasing rim lights, alien pilot, tractor beam with rings (ufo). Static parts are merged by `fuse()` → few draw calls.
- **Lip sync (v2.4):** `voice.py` writes a mouth track (opening + shape: open, wide, round, teeth, closed) for every line an on-screen character speaks (`BEATS[].who: 'you' | 'steve' | name`); `char(name)` lips follow it. Without voice: syllable rhythm.
- **Depth of field (v2.4):** real, depth-based lens blur. Auto in close shots (`CFG.dof: false` off, `CFG.dofAuto` strength), per key `dof` (0–1) and `focus: metres | [x,y,z] | track name` (rack focus between two keys).
- **Soft particles (v2.4):** smoke, dust and fire are camera-facing cloud puffs that fade in/out and follow the light (`CFG.softParticles: false` = old look).
- **Sea (v2.4):** `water()` reflects the sky (fresnel), turquoise shallows, whitecaps on rough seas, shore foam, no water on dry land. Underwater: SKY `'underwater' | 'deepsea'`, `underwater({ surface, caustics, shafts, plankton })` (moving caustics on everything, light shafts, plankton), `biome('reef')` (coral, seaweed, kelp, shells, starfish), `coral()`, `seaweed()`, `school({ n, at, r, colors, scatter })` (instanced fish), `shark(p, { kind: 'shark' | 'whale' })`, `jelly()`, `diver()` + `swim(rig, [[x,y,z]…], { t0, speed })` (bubbles), `submarine()`, emit kind `'bubble'`.
- **Weather & light (v2.4):** `fogBank({ at, r, density, drift })`, `lightShafts({ at, n, top, len, opacity })` (god rays along the sun), `lensRain(t0, t1, amount)` (drops on the lens).
- **Sound (v2.4):** real CC0 sound effects (`sfx/`, SFX Kit by Wyzowl) for boom, impact, whoosh, riser, thunder, splash, explosion, ding, stinger, pop, alarm, coin, ticks, drop, door, applause, fireworks, confetti — layered with the synth where it helps.
- **Voice (v2.4):** `BEATS[].tone: calm | tense | excited | whisper | shout | sad | dramatic` (tempo + loudness; dramatic = a beat before the *accent*), `' | '` in `say` = deliberate pause, every line levelled to the same loudness, de-esser, numbers spoken properly ($48.9K → "48.9 thousand dollars", 12% → "12 percent", km/h, °C, vs). Voices: deep (default), warm, documentary, storyteller (female), young (on-screen "you"), steve.
- **Reach (v2.4):** A/B thumbnails (`THUMB = [A, B]` → `-cover.jpg` + `-cover-b.jpg`), language versions (`assemble.py <slug> --lang es` + `<slug>.es.json` → captions, HUD texts and voice in Spanish; also fr, it, pt), publishing (`renders/<slug>.post.json` → `publish` workflow: YouTube scheduled via `publishAt`, Instagram Reels when due; setup in `upload.py`).
- **Physics (v2.5):** simulated once before the first frame with Rapier (deterministic build, 1/120 s steps → every machine and every render shard gets the same result), then played back by t. `phys(obj, { t0, mass, vel, spin, shape: 'box' | 'sphere', bounce, friction })` (falls, tumbles, bounces, stacks topple), `blast(x, y, z, t, { power, r })` (`explode()` adds one), `breakApart(obj, t, { n: [x, y, z], power, from })` (walls, sheds, fences shatter into chunks in their own colours), `ragdoll(rig, t, { from | dir, power, getUp })` (figures are thrown and go limp with jointed limbs; optional stand-up), `crash(vehicle, t, { impulse, spin })` (leaves its drive path, tumbles, glass, smoke), `collider(obj, { moving })` (houses, barns, silos, towers and vehicles are solid automatically). Needs `@dimforge/rapier3d-deterministic-compat` (installed by the workflow; the page loads it from the CDN otherwise).
- **Body dynamics (v2.5, automatic):** inertia — torso, head, hat, hair, coat and cape swing when someone starts, stops or turns (`CFG.inertia: false` off) · feet adapt to slopes (`CFG.footIK: false` off) · walking figures keep their distance · `carry(…, { heavy: true | kg })` leans back with strained arms.
- **Vehicles (v2.5):** `drive(…, { jumps: [[t, h, airtime]], bumpy: 0..2 })` — jumps with nose-up take-off, landing bounce and dust; off-road shake.
- **Water (v2.5):** `bob(obj, { drop: { t, from }, size, depth })` (falls in, splashes, sinks and pops up, pitches and rolls with the waves), `sail(boat, [[x,z]…], { t0, speed })` (rides the waves, leans into turns, wake trail, bow spray), figures wading through water splash with every step (automatic), emit kind `'spray'`.
- **Cloth (v2.5):** `cloth(p, { w, h, color, stripes, pin: 'left' | 'top' })`, `flagpole(p, x, z, { colors })`, `laundry(p, [[x,z], [x,z]])`, `figure({ cape: '#hex' })` — wave in the wind (stronger in storms), capes flow back when running.
